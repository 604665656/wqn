# 上下五千年 · 无尽编年

一个**离线单文件**即可游玩的历史分支页游：从公元前 5000 年的第一堆篝火点起，按家族／文明／人物视角推进；国内外史事以「本土 / 远闻」同时抵达，越过 2026 年进入明确标注的虚构推演。

## 四种开局

| 入口 | 内容 |
| --- | --- |
| 点燃第一堆篝火 | 通识推演：程序化无限分支、家族生老病死、卷末汇流、随机终章 |
| 代入真实血脉 | 12 个真实王朝／家族／文明之一，从考据年表的「建立」之年入局，走完建立 → 扩张 → 鼎盛 → 转折 → 衰落 → 终结 |
| 朝代长河 | 一局连走姬周 → 嬴秦 → 刘汉 → 李唐 → 赵宋 → 朱明（前 1046—1644）。每朝 12 笔＝一卷，卷末出更迭卡，前朝终结自动接下一朝；同一支家族贯穿六朝 |
| 文明条目 | 三种模式都会遇见 **20 维、563 条**考据条目，逐条带年代、可信度、出处与引文 |

## 真实内容怎么串起来

- **更迭链**：纪年首尾不重叠的政权才排成线性链。五段间朝（战国晚期、楚汉之际、三国两晋南北朝至隋、五代十国、元朝）如实留白，注明「本数据未逐朝收录」
- **不伪造更迭**：爱琴—地中海的 4 个政权纪年重叠，两河与南亚各只有 1 个年表，列为「并存政权群」，并做成**平行时间轴政权条带**横着看
- **人物随朝登场**：224 条文明条目按年代窗口映射到同期政权，本朝前几笔优先抽同期真实人物。卡片写明「年代窗口重叠，不表示隶属该政权或在其治下任职」
- **家族贯穿六朝**：改朝换代时同一支人续写编年（受封、失土、复籍、应举、经商、修谱），明确标为游戏推演
- **前置解锁树**：70 条依赖关系，印刷依赖造纸、微积分依赖解析几何与代数、摄影依赖光学与感光材料。前置未满足的条目不进候选池；年代倒挂的依赖自动忽略，不卡死
- **账本式写回**：旧例不只是文案回响，真实改写每笔的族和衰减、仓廪与文脉增速（族谱页可看当前账本）
- **人物生平四段**：12 位跨文明人物，生年／活动期／著述事迹／身后影响
- **鉴宝卡**：12 件知名器物，材质、出土或传世、现藏、鉴定要点、断代争议
- **考据玩法**：传说／后世追述条目多出「辨其传说」选项，判对得文脉，误断留一笔记录
- **出处分级**：747 条出处索引分「机构／学术」与「百科／媒体」，引文离线内嵌，断网可查

## 四种尽头与复盘

| 落点 | 做法 |
| --- | --- |
| 分卷结算 | 每 12 笔一卷，卷末汇流卡，可续卷或收卷 |
| 真结局 | 立例／血脉／编年／文脉／散族五条件；真实血脉与长河另有史料终章 |
| 随时收卷 | 完整报告：八维终值、实体六阶段、长河全程、史事、族谱、文明册、旧例、总评 |

**显示**：标准／大字／超大三档字号、高对比度模式、卡片淡入动画、手机竖屏七页签。

## 近现代：没做的一件事，如实说明

六阶段考据年表止于朱明 1644 年。**没有**为清、民国、当代编造「建立→鼎盛→终结」的六阶段实体，因为现有考据数据不足以支撑逐阶段的可靠节点。卷轴页改为列出 `data/history.json` 中已考据的**近现代可考锚点**（辛亥革命与清帝退位、联合国成立、苏联成立等），并写明 2026 年之后不作自动外推。政权条带是纪年视图，数据未含经纬度，因此不是疆域地图。

## 真实性纪律

- 分层：史实 / 断代争议 / 传说或后世追述 × 明确纪年 / 区间 / 约略 / 传说，传说层不进正式史实计数
- 不改写：玩家抉择只写回八维，不改人物生平、王朝终结年、技术史
- 并列争议：西罗马、阿拔斯、莫卧儿、奥斯曼等终结原因附学界不同口径
- 明确边界：蔡伦是改进推广而非发明纸；毕昇与古腾堡无直接传承证据；火药分四层；「玛雅崩溃」写城邦网络衰退；476 年是西罗马政治实体终结
- 条目是通识级整理，用于游戏语境，**不作学术考据之用**

## 直接玩

双击 `wqn.html`（或备用 `wqn.htm`），**用浏览器打开**。

- 安卓：文件管理长按 → 打开方式 → Chrome / 浏览器
- iPhone：存到「文件」App → 长按 → 共享 → 用 Safari 打开
- 后缀被改成 `.txt` / `.bin` / 无后缀 → 改回 `.html`
- 看到一页代码 = 打开方式不对，不是文件坏了

无联网、无依赖，自动存档于本机 `localStorage`，旧档自动迁移。

cd wqn

node tools/import_civilization.js
node tools/import_extra.js

## 加内容

改 `data/civilization.json` 的 `items`，字段：`id / dim / region / y0 / y1 / precision / rawYear / category / title / summary / status / consensus / refs / sources / boundary`。`dim` 取 `dimensions` 中 40 个键之一；八维写回由 `src/civilization.js` 按维度 `stat` 与门类自动映射。`unlocks` 里加一行即可新增前置依赖。改完重新构建。

补录批次（`addon:true`，物流／职业发展／教育／计量／婚姻家族／丧葬／体育／陶瓷冶金及医疗制度补录）为通识级整理，出处沿用既有考据索引，`sourceNote` 已注明未逐条绑定单一文献；新增维度请优先走带出处的正式考据流程。

## 真实性档位与玩法

`src/reality.js` 定义三档（考据／兼容／狂想）、五玩法（编年／考据／鉴宝／存续／沙盒）、四时长（短局／标准／长卷／无尽）与四档史料密度。开局与设置页均可切换，分享串带完整配置以保证复盘一致。史实字段永不被抉择改写；「文本传统」「未证实假说」「史前可考」与史实四层严格分离，见 `data/fringe.json`。
