# 《上下五千年·无尽编年》史料考据与结构化游戏数据报告

## 摘要
本报告从公元前5000年至公元2026年，按七个文明圈整理72条可考历史节点，并以12个跨文明王朝、家族或文明体建立六阶段年表。全部条目均要求“单条可核验”：含年份窗口、事件标题、客观事实、至少一种权威出处及史实属性；年代不确定者单列，不并入确证事件。七圈条目数为华夏·黄河12、两河·新月沃地10、尼罗·埃及10、爱琴—地中海/罗马10、印度河—南亚9、中美洲11、欧亚草原10，共72条；其中58条可按学界通说使用，11条仅能给出约略年代或存在断代争议，3条属于后世追述、传说或不可直接当作信史。[1][2][3][4] 实体表中，姬周、嬴秦、刘汉、李唐、赵宋、朱明、美第奇、哈布斯堡、罗马共和国→帝国、阿拔斯、莫卧儿、奥斯曼的六阶段均可锚定明确年份或约略年代；蒙古帝国及若干终结原因仍需以多口径呈现，不应把单一说法固化为唯一结论。[5][6][7]

## 一、考据口径、字段约定与转 JSON 建议

**本报告的年代与史实属性字段直接服务于游戏数据化，而不是提供历史解释。** 建议将每条事件转为一个 JSON 对象，字段统一为：`id`（E+三位序号）、`civilization_circle`（七选一）、`start_year`（早于公元1年用负值）、`end_year`（单点事件与`start_year`相同）、`date_precision`（"exact"、"range"、"approximate"、"legendary"）、`title`、`summary`、`status`（"学界通说"、"断代有争议"、"属传说或后世追述"）、`sources`（字符串数组）。其中 `start_year/end_year` 使用天文纪年：公元前1年为0，公元前2年为-1，公元后沿用原数；这样可避免程序出现“公元0年”。`date_precision` 为 `legendary` 的条目即使有后世给出的传说年代，也不应与确证事件共用时间轴权重。

年代可信度分为三层：有明确纪年者指可据正史、铭文、档案、可靠测年或学术研究给出单年；约略者指只能给出较宽年代窗口；断代有争议者指在既有研究或不同史料之间仍有互不相容的纪年方案。夏代、三皇五帝、早期传说人物属于不同问题：夏是否存在有考古与文献讨论，但约前2070—前1600年并非无争议的单一年表；黄帝、尧、舜在《史记》中被系统追述，却缺少可与殷墟卜辞、金文同一等级的当代文字证据。[1][8] 因此游戏不应把“黄帝元年”“尧在位百年”等当作可计算历日。

**跨文明比较应优先使用“事件锚点”，而不是把王朝起止视为全球同步阶段。** 本报告所选实体并不构成一个覆盖全球的政治体系；它们只是具有较长持续时间、明确转折点或高数据可用性的样本。六阶段字段为 `entity_id`、`name`、`phase`（建立/扩张/鼎盛/分裂或转折/衰落/终结）、`year` 或 `year_range`、`precision`（"exact"/"approximate"）、`event`、`end_reason`、`end_reason_disputed`。同一政治体可以出现多个“分裂或转折”节点；若无法可靠区分“衰”与“终”，应保留原史料中的政权名变化，而不强行合并。

## 二、华夏·黄河：从考古文化到近代共和

**华夏条目的长时段主干清晰，但公元前841年以前仍不能等同于一串无争议的单一年份。** 可资利用的最早连续纪年由《史记》体系上推至西周晚期共和元年，即公元前841年；此前夏商周断代工程给出研究性方案，而非消除了全部分歧的绝对历表。[1][8] 因此前841年可作为“连续纪年窗口”的可靠上界，而更早事件的年份只宜标为研究方案或约略年代。

## 三、两河·新月沃地：文字、法典与帝国更替

**两河条目的优势是早期文字与政权名称较连续，难点在于“帝国”“统一”和现代国界不能混用。** 约前3200年苏美尔人使用楔形文字、前2334年萨尔贡统一南部两河流域，均有全国哲学社会科学工作办公室的专门文章支撑。[2] 但“第一次统一”是指阿卡德王国把南北政治中心纳入同一统治体系，并非此后两河再无独立城邦；“文明终结”也不应表述为文化彻底消失，因为楔形文字传统延续至公元前后。

|---|---|---|---|---|

**“法典年代”适合做精确锚点，城市起源与文明衰落则更适合用区间。** 乌鲁克、埃利都等遗址并非同时出现全部国家特征；考古文化内部还存在多中心竞争。故数据表中将前5000年、前3500年、前3200年标为 `approximate`，以免把连续演化压缩为虚假单点。

## 四、尼罗·埃及：统一王权、帝国扩张与文本断裂

**纳尔迈调色板可以证明王权象征与早期统一叙事，不能单独证明现代意义上的全国统一。** 中山大学讲座将调色板年代定在前3100—前3000年，并将其解释为上下埃及统一的重要视觉证据。[3] 古王国金字塔、新王国东扩、卡迭什条约与托勒密王朝构成相对连续的事件链，但古埃及文字传统在罗马、基督教与阿拉伯统治下逐步退出日常使用，故“文明终结”应理解为政治—宗教—文字体系转型，而非人口消失。

## 五、爱琴—地中海与罗马：城邦、共和、帝国和地中海网络

## 十、实体终结原因的争议与替代解释

**终结原因普遍不是单一因素，史学分歧在于主因排序、因果顺序与事件定义。** 游戏可将确定事实、主流解释和替代解释分层显示：例如“西罗马末帝于476年被废”是事实；“蛮族入侵导致其灭亡”是一种解释；“气候、瘟疫、内战与蛮族迁移共同作用”是更谨慎的多因素模型。两者不应放在同一可信度层级。

| entity | 终结年份 | 本报告采用的综合原因 | 学界不同口径 |
|---|---:|---|---|
| 姬周 | 约前256 | 秦兼并王畿、周赧王被废，东周祀亡。 | 若把周代视为文化—礼制连续体，则不能以前256年断为“周文明终结”；若以王权政治体计，则可终结于该年。 |
| 西罗马 | 476 | 长期内战、财政危机、军队蛮族化及日耳曼迁徙压力共同导致独立帝国终结。 | 吉本式道德解释、基督教影响论、蛮族入侵决定论、奴隶制危机论、气候—瘟疫模型并存。[64][67] |
| 古埃及新王国 | 约前1077或以后 | 海人冲击、利比亚人与努比亚势力介入、王室与祭司权力失衡、粮食经济受气候影响。 | 是“新王国晚期国家转型”还是“外族征服导致崩溃”，取决于把第二十、二十一王朝归入埃及延续还是断裂。[3][23] |

**多因素解释不等于取消主因，而是要求把主因明确标为解释模型。** 例如，西罗马的476年可作为确定程序节点，但其历史原因字段可写成：`{"primary_factors":["军队与行政蛮族化","财政与征兵危机"],"secondary_factors":["气候压力","瘟疫","日耳曼迁徙"],"interpretive_disagreement":true}`。这种结构既满足编年游戏的确定性需求，也保留史学争议。

## 十一、可直接落库的 JSON 结构与校验规则

**推荐最小 JSON Schema 应同时保留“机器判断”和“人类阅读”字段。** 事件文件可命名为 `events.json`，实体文件为 `entities.json`，争议说明为 `disputes.json`。事件对象如下：

```json
{
  "id": "E001",
  "civilization_circle": "华夏·黄河",
  "start_year": -5000,
  "end_year": -5000,
  "date_precision": "approximate",
  "title": "裴李岗等黄河流域早期农业文化出现",
  "summary": "黄河中游出现定居农业、石器与陶器遗存，构成早期农耕社会证据；无法还原为单一事件。",
  "status": "学界通说",
  "sources": [
    "《人民日报》云观展《亚洲文明肇始，你知多少？》"
  ]
}
```

实体对象应使用阶段数组而非把六阶段塞进平铺字段，以便部分阶段为区间时不会造成歧义：

```json
{
  "entity_id": "C01",
  "name": "姬周",
  "type": "dynasty",
  "phases": [
    {"phase":"建立","year":"前1046","precision":"exact","event":"武王克商，建立西周","end_reason":null},
    {"phase":"终结","year":"约前256","precision":"approximate","event":"秦攻取周王畿、废周赧王","end_reason":"秦兼并王畿，周祀终结"}
  ],
  "dispute_note": "西周亡于前771年；东周王室继续存在，前256年才失王畿祀统。"
}
```

**导入校验至少执行四条规则。** 第一，所有 `start_year` 必须存在；`end_year` 缺省时继承 `start_year`。第二，`date_precision` 为 `legendary` 的事件不得进入“连续纪年事件”筛选结果。第三，跨公元前/公元后的差值必须按天文纪年计算，例如从秦统一前221年到清帝退位1912年间隔2132年，而非“1912−221=1691”。第四，实体中 `precision` 为 `approximate` 的节点不得与 `exact` 节点使用完全相同的显示样式；可在前端以“约”或模糊光圈表示。

**争议字段需要三种状态，而不是简单“有/无争议”。** 可设 `consensus_status`：`settled`（学界通说）、`date_contested`（年代有争议）、`entity_definition_contested`（实体边界或终结定义有争议）、`legendary_retroactive`（传说或后世追述）。这样，夏代可同时具有 `date_contested` 与 `legendary_retroactive` 两层含义，匈人—匈奴关系则为 `entity_definition_contested`。

## 十二、用于《无尽编年》的游戏化建议与限制

**编年玩法应以“时间可锚定、因果可选、传说分层”为核心。** 对 `exact` 节点可开放时间排序、地图定位、材料核对等玩法；对 `approximate` 节点只要求排序到正确世纪或年代区间，避免玩家因约略年代答错而接受错误信息。对 `legendary` 节点可设为“后世记忆”或“追述层”，奖励玩家识别传说与当代证据之间的差异，而不是奖励把传说当作信史。

**跨文明同步比较必须避免把异质时间单位强作胜负。** 公元前3000年的乌鲁克、约前3100年的纳尔迈、前2686年起的古王国并非“谁统一更早”的简单竞赛：统一对象、文字证据、政治组织和国家定义均不同。游戏可用“已知最早”“可文字验证”“形成长期王朝”等不同成就标签，替代一个看似精确、实质不可比的“最早”排名。

**本报告的截止点为2026年，2026年内发生的后续事件不能据既有条目自动外推。** 报告中的2026年节点主要用于说明现代国家与联合国体系持续存在，不表示2026年发生全球史意义上的新增重大转折。若后续制作动态内容，应另行补充当年官方资料，而不把本报告中的占位说明当作年度事件。
