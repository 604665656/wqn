# 分路声音与无障碍（v1.3 · 第十三轮）

> 这轮把三件一起做了：**音效／背景音分开开关**、**朗读**、**语音控制**，
> 并按「读屏也能玩」的标准把界面补了一遍。当前版本 **v1.3 · build 4**。

---

## 一、音效与背景音：真的分开了

上一版只有一个总开关，关掉就全没声。现在两路独立：

| 路 | 包含 | 独立开关位置 |
| --- | --- | --- |
| 音效 | 落笔、判读三档、研习、汇流、更迭、收卷、验收、警觉（11 种短音） | 右上角「音效」、设置页「音效 开／关／试听」 |
| 背景音 | 6 种底噪 + 9 首缓慢曲目循环 | 右上角「背景」、设置页「背景音 开／关／按本局配乐」 |

- 关音效**不**影响背景音；关背景音**不**影响音效；「全部静音」一次关两路
- 音量、调式、曲目、底噪仍共用一套设置，但只作用于背景音那一路
- 旧配置只有一个 `on` 字段：载入时按原状态迁移（原本静音就仍静音），不用清档
- 实测：音效开／背景关 → 音效关／背景开 → 全部静音，三态互不串扰

## 二、朗读（speechSynthesis）

- 设置页开「朗读」后，点右上角「朗读」或「试读本页」，把当前页念出来：
  年份、卷次、卡片正文、结果、卷末汇流，**逐条读选项**（含收益／代价／失手提示），末尾报可点的按钮
- 「自动朗读新一笔」：每换一笔自动读简版，笔数或阶段不变时不重复念
- 语速三档（慢 0.85 / 中 1 / 快 1.25）、详略两档（简／全）
- 长文本切成 ≤170 字的短段依次朗读，避免某些引擎吞掉整段；超长编码串（分享串）自动截断
- 优先挑中文语音；「停读」立刻清空队列

**边界**：朗读是浏览器原生合成语音，不是配音、不是历史文本复原；
不联网、不上传、不写存档与分享串。

## 三、语音控制（SpeechRecognition）

必须**用户主动点开**才使用麦克风，页面加载时绝不自动申请权限。

可以说：

```
选一 / 选二 / 第三个 / 按五 / 9
继续 / 下一笔 / 往前
收卷 / 续卷 / 终章 / 更迭
设置 / 去族谱 / 打开文明 / 看舆地
朗读 / 读一遍 / 停 / 别念了
开音效 / 音效关 / 开背景 / 关配乐 / 静音 / 开声音
停止语音 / 关闭语音 / 帮助
```

命令解析是纯函数，31 条说法逐条有测试；听不懂会播报原话并提示可以说「帮助」。
每条执行结果写进 `aria-live` 实时播报区，开了朗读时也会念出来。

**降级要说清楚**：`file://` 本地文件下，部分浏览器（尤其移动端）不提供语音识别接口，
或会拒绝麦克风权限。此时界面如实显示「不提供／已拒绝」，**键盘操作始终可用**。
有些浏览器接口存在但本地环境启动失败，也会提示改用键盘，不假装成功。

**隐私**：不上传、不录音、不保存任何语音；关闭立即停止识别；麦克风状态不写存档。

## 四、读屏友好做了哪些

| 项 | 做法 |
| --- | --- |
| 跳转 | `skip link`：聚焦后跳到主内容 |
| 语义 | `#app` 加 `role="main"`；页签 `role="tab"` + `aria-selected` |
| 播报 | `aria-live="polite"` 实时区，操作结果、命令回显、页签切换都报 |
| 选项 | 每个选项 `aria-label="选项 N：标题，收益…，代价…，有失手可能"` |
| 装饰 | 所有程序化插画标 `aria-hidden="true" focusable="false"`，读屏直接跳过 |
| 焦点 | `:focus-visible` 金色描边，高对比度下加粗；尊重 `prefers-reduced-motion` |
| 键盘 | 1–9 选项 · 回车继续 · ←→ 切页签 · R 朗读 · S 停读 · V 语音 · M 静音 · ? 帮助 |

输入框、下拉、文本框里按键不拦截，避免和表单操作打架；带 Ctrl / Alt / Cmd 的组合键也不拦。

**这不替代专业读屏软件**，是把结构补齐让它读得顺：所有信息本来就是文字，插画只是装饰，
关掉插画（「纯文字」）不影响任何内容与玩法。
