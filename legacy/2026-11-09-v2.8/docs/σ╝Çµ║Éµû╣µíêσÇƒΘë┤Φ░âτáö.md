# 同类型成熟开源方案 · 借鉴调研

> 调研日期：2026-11-08（Asia/Shanghai）　对应工程：**v2.5 · build 16**
> 口径：官方仓库 / 项目站优先；二手榜单只作线索，**许可证一律回官方核实**。
> 本轮**只调研，未改可玩文件**，因此版本号保持 v2.5 · build 16，未触发自动递增。

---

## 0. 结论先说

1. **没有完全同构的成熟开源项目**。当前工程是「史实考据 + 世代族谱 + 判读题 + AVG 舞台 + 离线单文件 + 送审合规」六合一；市面方案各自只覆盖一到两块。正确做法是**按模块借鉴，不迁移引擎**。
2. 三条硬约束决定不能整体换运行时：**`file://` 双击即玩**、**同种子逐笔复盘**（主随机数纪律）、**送审六类敏感措辞零命中**。引入 React / Pixi / WebGAL 这类运行时会同时破坏前两条，或显著扩大审核面。
3. **史料数据有红线**：CBDB、CHGIS、ctext Data Wiki 都是「非商业 + 限制再分发」，不能直接灌进离线单文件再分发。现状「只给域名级检索入口 + 自建通识锚点、引文留空、不作学术引用」是对的，应继续保持。[citation:17][citation:21][citation:26][citation:31]
4. **二手榜单的许可证不可信**：某 2026 年开源工具榜单把 Ren'Py 写成 MPL-2.0 [citation:2]；Ren'Py 官方许可证页实际是**主体 MIT + 需满足 LGPL 合规**，官网也明确开源且可商用 [citation:1][citation:7]。引入任何库前必须看仓库 `LICENSE` / 官方 licensing 页。

## 2. 最值得抄的 8 件事（按优先级落地）

### P0 · 不引依赖、不动架构

1. **叙事中间格式**：现有 `data/*.json` 已是数据驱动，但「判读题三择一、立场权重、选项→表演层映射、边界标签」还散在 JS 里。借鉴 ink 的 knot / choice / 条件写法 [citation:8]，定义一层纯文本或 JSON 中间格式（条目 ID + 条件 + 选项 + 后果 + 表演层 + 可信度/边界标签），由 `build.js` 编译成现有结构。**运行时一行不改**。
2. **回想日志 / 自动播放 / 跳过**：Ren'Py 与 Monogatari 都自带 [citation:3][citation:9]；v2.5 有编年但没有「回看已读正文」。加一页「回想」，只记本局已显示的正文与选项，读屏同样可用，不进分享串。
3. **audio 时钟与时值**：现有 Web Audio 振荡器可包一层 Transport：统一 tempo、`8n`/`4n`/`1m` 时值、ADSR 包络、按情境排队。Tone.js 明确要求**用户手势后** `Tone.start()` [citation:25]，与工程「默认静音 + 首次点击开声」一致，可直接对照写回归断言。
4. **`file://` 自检清单**：vite-plugin-singlefile 列出可用（`localStorage`、同目录相对资源、hash 路由）与不可用（cookies、History API、动态 `import()` 分片、Worklets）[citation:34][citation:37]。构建后自检在现有「校验和 + 字符串池 + blob URL」之外，再加三条：**无外部请求、无 dynamic import、无 cookie**。
5. **许可证核实流程**：把「只认仓库 `LICENSE` / 官方 licensing 页」写进引入规范。榜单把 Ren'Py 写成 MPL-2.0 [citation:2] 而官方是 MIT + LGPL [citation:1][citation:7]，就是现成的反面案例。

### P1 · 抽纯函数内嵌

6. **关系图布局**：四种继嗣制（父系 / 母系 / 双系 / 从妻居）现在用自绘 SVG 分层，长局节点多时易重叠。借鉴 family-chart 的层次布局与姻亲/继嗣边分色 [citation:23][citation:24]，抽成纯函数内嵌，**不引 D3**。
7. **参数化 idle**：现在四种待机动作是固定 CSS 类 + 固定散列。借鉴 Iki 的 `IdleMotion`（眨眼 / 呼吸 / 凝视漂移 / 头摆 / 物理回弹作为可组合驱动）[citation:28]，减少「每加一个动作写一段 keyframes」。
8. **错答复现**：现在判读题「答过不重出」。借鉴 FSRS 的「错项按间隔复现」[citation:19]，但**间隔必须由种子 + 题号固定散列算出**，不能用真实时间或随机，以保住同种子逐笔复盘。

### P2 · 观察

- 语音命令匹配可对照 annyang 的「命令表 → 回调 + 可选参数」写法 [citation:35]；工程已用原生 Web Speech API，不必引 2 KB 库。

## 3. 明确不建议引入

- **整引擎**：WebGAL 需 HTTP，`file://` 双击必黑屏 [citation:13]；Twine 编辑器 GPL-3.0；Anki 桌面 AGPL-3.0 且网络分发有源码义务 [citation:19]；Ren'Py 偏重、Web 构建仍是 Beta [citation:1]。
- **史料数据**：CBDB 自 2026-08-20 起，超出当前单机版范围的数据适用「署名 + 非商业 + 禁演绎 + 禁再分发与公开数据访问服务」[citation:17]；CHGIS V6 明确「仅学术研究，禁商用、转售、再分发」[citation:26]；ctext Data Wiki 为 CC BY-NC-SA 3.0 且要求在线复用时保留实体链接 [citation:31]。**任何一条都不允许把它们打包进离线单文件再分发。**
- **Live2D Cubism Core**：源码 MIT 不等于整体可用，Core 受 Live2D 自有许可且模型各有条款 [citation:29][citation:32]。
- **任何 CDN / 外链**：破坏离线与送审。

## 4. 顺带把「横屏」也查了

`screen.orientation.lock()` 属于 **Limited availability**：Android Chrome 支持，**iOS Safari、桌面 Chrome / Safari 均不支持** [citation:38]。所以此前「点横屏完全横不了」不只有系统竖屏锁定，还有浏览器支持差异。

v2.5 的做法——**重排成全屏横向布局 + 监听 `orientation` 自动适配 + 如实提示「网页改不了系统旋转」+ 不假装已旋转**——与平台实际能力一致，建议保持；不要试图用 Fullscreen + `lock` 强行统一。
