# v2.7 · 左右可调横向画布与向导台词

> 当前 **v2.7 · build 18**。这轮全部来自你那张真机截图。

## 一、默认改成猫左字右，而且左右能调

之前横向画布是「字左猫右」，这轮按图改成**默认猫在左、字在右**。三种调法：

| 入口 | 做什么 |
| --- | --- |
| 设置页「文字区占比」滑杆 | 35–65%，步进 1% |
| 画面中间那条细线 | 按住直接拖，横屏／假横屏都能拖 |
| 「一键互换」/「复位」 | 整体左右对调 / 回到 47% 猫左字右 |

分栏只改显示，写进本机设置，不进存档、不进分享串。字那一侧放选项、进度 chip、工具条；猫那一侧放对话气泡与点按台词气泡，顶部不再叠成一堆。

## 二、「猫难拖动」是真 bug，不是手感问题

旋转 `90deg` 后，代码仍把**屏幕位移** `dx/dy` 直接当成**画布位移**。CSS 矩阵是 `matrix(0,1,-1,0,...)`，换算关系是：

```
容器水平 u = 屏幕 Δy
容器垂直 v = -屏幕 Δx
```

不换算就是「手指往右拖、猫往上下跑」。这轮改成 `rotDelta()` 统一换算，并补了四件事：

- **猫专用透明热区** `#charHit`：命中框明确，不再靠旋转后的 AABB 猜位置
- `touch-action:none` + `setPointerCapture`：iOS 上手指不会被系统滚动手势抢走
- 阈值 4→3、限幅 140→180：更跟手、可拖动范围更大
- 拖动中给 `html` 加 `dragging-char`，让呼吸与待机动画让位，避免 transform 又被 CSS 抢走

实机：竖屏假横屏下屏幕下移 70px → `--char-dx: 70px`、`--char-dy: 0`，方向正确；点按与长按表情面板仍互不误触。

## 三、点猫多说话，语音包接口留好

新增 **29 条向导台词**，按 7 组情境轮换：闲笔 6 / 判读 5 / 营作 5 / 交易 3 / 族谱 4 / 卷末 3 / 天气 3。点一下出一句，半透小气泡显示 3.2 秒，透明度沿用你已经调过的全局气泡值（`--veil`），文字带描边与浅色光晕，最透档也看得清。

**语音包接口**（现在只是接口，不是配音包）：

```js
character.voicePack = {
  enabled: false,
  format: 'audio/webp',
  entries: {},          // 后续按 voice id 填离线 data URI / blob URL
  note: '...'
}
guideLines.idle[0].voice === 'g_idle_01'
```

后续把语音按 id 填进 `entries`、把 `enabled` 置 `true`，运行时会调用 `W.guideVoice.play(id, src, text)`；**界面代码不用改**。当前为空实现：朗读开启时由系统语音代念，否则只出文字气泡与轻声短音。全部离线，不引外部资源。

台词轮换用模块内计数，**不调用主随机数、不写存档**，同种子仍逐笔可复盘。

## 四、「退出全屏和推演那些没横过来」

查出来是 DOM 层级问题：页签 `#tabs` 和退出条 `#landHint` 挂在 `body` 下，不在旋转的 `#app` 里，所以游戏内容侧躺、它们却是正的，看着一半正一半倒。

- rot90 时把两者**移入旋转容器**，改用 `absolute` + 百分比定位
- `render()` 的 `app.innerHTML` 会冲掉它们，所以每次重绘后 `rotChrome()` 自动补建
- 退出横屏时 `unrotChrome()` 移回 body
- CSS 隐藏白名单补上 `.tabs`，避免被横屏规则一起收掉

顺带修了截图里另一个问题：退出条原先在**字那一侧** `bottom:11%`，正好压住选项卡片。现在移到**猫那一侧底部**，那侧没有选项，压住的只是猫的下半身（半透仍看得见）。

退出仍是四个出口：常驻「退出横屏」、横屏键再点（真 toggle）、Esc、× 收起说明。竖着拿时退出条跟着画布侧躺；横过来看时它正着，横屏键 ▯ 也正着并高亮。
