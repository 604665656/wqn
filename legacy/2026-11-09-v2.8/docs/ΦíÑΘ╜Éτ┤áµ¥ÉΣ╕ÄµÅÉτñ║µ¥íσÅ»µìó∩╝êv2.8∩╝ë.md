## 三、「横向画布气泡换不掉」

你截图里那一整块**竖排大字**是 `#landHint`：它原本写死一段说明、无任何设置入口，横屏时又跟着画布转 90°，竖着拿手机就成了一竖条。

现在设置页有「**横向画布 · 提示条**」卡片。默认**固定在屏幕**：竖着拿手机时它是正着的横排小胶囊，横着拿手机时视口跟着转、它也正着；页签仍留在旋转容器里与画面一起横过来，两者各司其职。

| 设置 | 作用 |
| --- | --- |
| 精简（默认） | 一行小胶囊，只留标题＋拖柄＋退出；不再是竖排说明块 |
| 完整说明 | 保留原来那句「把手机横过来看，网页改不了系统方向」 |
| 隐藏 | 彻底不显示 |
| 跟随画布旋转 | 默认关（固定在屏幕、永远正着）；打开才与画布一起横过来 |
| ⠿ 拖柄 | 按住拖动，左右不出屏、上下至少留一截可见 |
| 复位 | 回到精简＋跟随＋原位 |

底色透明度**跟随全局 `--veil`**（你调过的那个 35% 滑杆），文字加深色描边与浅色光晕，半透下仍看得清。

**隐藏了也不会换不回去**，三个出口都在：`Esc`、设置页「横屏布局 → 关」、主页工具条高亮 `▯`。提示条只存本机，不进存档与分享串。

## 四、顺手修了一个真误报

新增的 8 张内嵌图片里，WebP 的 base64 恰好随机出现 8 次字母串 `UFO`，`audit_copy.py` 把它当敏感文案扫出来，送审版从 0 命中变成 8 命中。修法不是改图，是**只审人会读到的可见文案**：把 `data:image/...;base64,` 的载荷按等长空格剥离后再扫。并加了自测——正文里真写了 `UFO` 仍会被拦下，没有放宽审核。

## 七、交付前又收了两处口子

- **变更日志自摆乌龙**：v2.8 的 changelog 里为了说明「base64 误报」，把那个三字母敏感词原样写了进去；它会随 `version.json` 内嵌进送审版，于是 `audit_copy --strict` 又报 1 处、送审回归也挂。改成「某三字母串」后重新构建，六类回到 **0 命中**。审核剥离 base64 载荷的逻辑本身没动、也没放宽——正文里真写那个词仍会被拦下，专项自测还在。
- **两套旧断言同步到新结构**：v2.8 提示条默认固定在视口（`body`）、不再跟着画布转，而浏览器全流程断言还要求它「在旋转容器内」；iOS 专项的字段名也仍是旧的。两处都改成「提示条在 body 固定、页签在 #app、退出按钮可点」的新口径，实测全绿。
- **版本代号残留**：`WQN_VERSION` 里的 `codename` 一直显示十几轮前的旧代号，因为版本递增时只写了 changelog、没同步代号。现在 `build.js` 会直接取本轮 `pending.title` 更新它，以后不用手工改。
