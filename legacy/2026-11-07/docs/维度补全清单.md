## 三、明确不做的

- 把「史前超文明／古代宇航员／外星人」当史实或默认内容——只作狂想档里红色标注的虚构素材
- 把并立政权硬串成单线王朝更迭——只列并存
- 用气候决定论解释某朝灭亡——只写时间相关，不写因果
- 编造清、民国、当代的六阶段实体年表——考据密度不够
- 把野史、小说、演义的叙述写进正式史实编年

## 四、补一维的标准动作

1. 先写 `docs/史料考据-XX.md`，表格逐条带年代、可信度、出处 URL
2. `tools/` 加导入脚本，或按 `build_final.js` 的 `RAW_ADDON` 格式补录并标 `sourceNote`
3. `civilization.json` 的 `dimensions` 登记 key / name / badge / stat / desc
4. 条目写 `boundary`（该维的失真风险），必要时加 `unlocks` 前置
5. `node tools/build_final.js && node build.js`，再跑三套测试

> 补录维默认只给「通识级整理 + 既有出处索引」，要走正式考据流程才标 `consensus: settled`。
