# 声与色（v1.2 · 第十二轮）

> 你要的「美术和音乐」做完了，仍是**离线单文件、不联网、手机浏览器直接开**。
> 当前版本 **v1.2 · build 3**（版本号机制自动递增，见 `版本记录.md`）。

---

## 一、为什么是「程序化」而不是塞古画古乐

三条硬约束决定做法：

1. **单文件离线**：不能引用外部图片、字体或音频文件，也不能联网取资源。
2. **上次审核刚被拒过**：真实历史图像涉及旗徽、政权范围、信仰符号等，风险很高；
   直接用现成古画还有版权与来源问题。
3. **同种子必须可复盘**：画面和声音不能消耗主随机数，否则对照局会漂移。

所以美术是 **SVG 几何图形实时绘制**，音乐是 **Web Audio 振荡器实时合成**。
文件体积只增加约 40 KB，仍然一份 HTML 走天下。

## 二、美术：9 套色板 / 12 种纹样 / 8 类场景

| 项 | 内容 |
| --- | --- |
| 时代色板 | 新石器→青铜→轴心→帝国→中古→大航海→工业→当代→推演，共 9 套，每套 9 个色值 |
| 几何纹样 | 绳纹、回形折线、曲折带、联珠、卷草、水波、齿纹、方格、星点、锯齿、苇叶、阶梯 |
| 器物剪影 | 聚落、器、柱、行旅、券、舟、轮、塔、环、泥板、苇、印、阶、马，共 14 类氛围索引 |
| 场景 | 开局第一堆篝火、抉择横幅、卷末汇流、终章收卷、更迭、族谱、舆地、文明册 |

**画面会随局变化**：年代、文明圈、时代、卷数进固定散列 → 同一参数必得同一张图；
换卷、换时代自动换色换纹。开局是篝火与远山，卷末是月、河、卷轴，终章是远山孤树与虚线小径，
更迭是双色带与门形，族谱是树，舆地是罗盘与水线。

**界面位置**：每页顶部横幅／场景，右上角声音按钮，设置页「声 与 色」面板可一键切「纯文字」。
高对比度模式下描边自动提亮。

**边界**：不描摹旗徽与任何范围表达，不对应具体考古纹饰复原，不画政权范围、边界线、
信仰符号；色板只按时代换气氛，不表示政权、族属或范围归属。

## 三、音乐：8 调式 / 9 曲目 / 6 底噪 / 11 音效

- **调式**：五声宫、五声羽、西亚增二度列、地中海多利亚列、南亚上行音列、
  中美洲五声列、草原四声列、近世等分列。每档标了适合什么题材。
- **曲目**：编年慢板、长河行、行旅、海岬、季风、石阶、长风、近世、收卷，
  各有速度、音型与说明；「按本局配乐」会按文明圈与时代自动挑一套。
- **底噪**：静 / 风 / 篝火 / 雨 / 水 / 市井，全是程序噪声与低通缓变，不含语音。
- **音效**：轻触、落笔、研习、判读稳妥 / 按通说 / 误读取、汇流、更迭、收卷、验收、警觉。
  判读题选哪一档，短音不一样。

**浏览器限制**：默认静音，必须用户点一下才出声（浏览器自动播放策略）。
右上角按钮一键开关；设置页可调音量三档、三个下拉（调式／曲目／底噪）、试听、自动配乐。
页面切到后台自动挂起，回来恢复；关闭后不产生任何音频节点。

**边界**：调式只是常见的音阶组织方式，用于氛围，**不宣称是历史曲目、礼制用乐、乐律制度
或考古复原录音**；所有声音都是实时合成的示意音。配置只存本机浏览器，
不写游戏存档、不进分享串，同种子仍逐笔可复盘。
