# 抉择后果系统 · 第二层

> 日期 2026-11-05，对应 `wqn.html` / `wqn.htm`。
> 上一轮治的是「选项太单调」：把当时 961 条考据知识变成可打出的牌。
> 这一轮治的是「打出去就没了」：让一张牌跨好几笔继续活着。

---

## 一、为什么还要再深一层

上一版做完之后，选项确实丰富了，但有个残留问题：**每个选择都在同一笔里结清**。
点了「开渠」，加几点粮，下一笔就忘了；见过《齐民要术》也只是多一张收集卡。
玩家不需要记着自己做过什么，也不需要为三笔之前的一个决定负责。

这一轮补的是「后果的时间维度」——五件事：

| | 机制 | 玩家能感觉到什么 |
| --- | --- | --- |
| **A** | 多轮决议 | 开渠之后，后面几笔还会跳出「岁修 → 验收」，也能「罢手」但投入不退 |
| **B** | 职业反哺 | 族里有了渠工，水利类选项收益 ×1.25、更容易出现，卡上明写 |
| **C** | 考据分歧 | 已见的「断代争议／传说」条目与同维度通说配对，出一对互斥取舍 |
| **D** | 跨维组合技 | 造纸 + 印刷 + 取士都见过，才出现「刊刻试本」这类高阶选项 |
| **E** | 未走之路 | 每笔被放弃的 2—5 条留档，卷末与收卷报告能回看「当时没走的路」 |

外加 **编年时间轴**：卷轴页顶部一条横向轴，卷界、史事、迁徙、工程节点、当前年份一屏看完。

## 二、A 多轮决议：工程链

`data/consequences.json` 定义 5 条工程，每条 3 笔：

| 工程 | 触发原型 | 三笔 | 验收后的长期账本 |
| --- | --- | --- | --- |
| 渠堰 | 营建（水利／农业／建筑） | 立项 → 岁修 → 验收 | 仓廪／族和衰减略缓 |
| 织坊 | 工造（纺织／工艺／材料） | 试造 → 供料 → 成货 | 货殖／百工衰减略缓 |
| 授时台 | 工造／研习（计时／星象／历法） | 立表 → 校刻 → 颁历 | 文脉／祭祀衰减略缓 |
| 册库 | 研习／治理／传承（文化／法律／教育） | 抄录 → 校雠 → 立目 | 文脉／族和衰减略缓 |
| 航路 | 交易／冒险／迁徙（航海／商业／物流） | 备船 → 探路 → 立契 | 货殖／文脉衰减略缓 |

- 普通营建／工造类选项有 34% 概率**挂起**一个工程；同时在办最多 2 个，避免整屏都是续作。
- 后续笔里，续作选项**强制露面**（不会被加权抽掉），卡上写「工程第 2/3 笔 · 〈依据条目〉」。
- 每段各自带收益、代价、失手概率；验收完成写 `projectLedger`，并入 `engine.ledger()`，跟旧例共用同一套衰减公式。单维账本加成封顶 34%，不会滚雪球。
- 随时可以**罢手**，沉没代价明确写在卡上：「半途而废，夫料散了，只留一道未成的渠口」。
- 验收进里程碑：「工程既成 · 渠堰（N 年 / 3 笔）」，收卷报告有「跨笔决议 · 工程账」。

**这一条最关键**：它让「一笔」不再是后果的最小单位。三笔前点的那一锹土，现在还挂在账上。

## 三、B 职业反哺

族中业（渠工、织匠、司辰、书记、舟师…）不再只是族谱上一行字：

- 已有该业的原型，收益 ×1.25、权重 ×1.32；
- 卡上追加「族中有人习此业「渠工」· 收效↑」；
- 工程续作同理加成；
- 于是「先派人学这门手艺 → 后来同类抉择更划算」成了可感知的策略线。

## 四、C 考据分歧：二择其一

原有 961 条里有 **136 条「断代有争议」+ 16 条「属传说或后世追述」**。以前它们只是被标出来，现在会主动来敲门：

- 当本局已见过 ≥2 条争议／传说条目，按 34% 概率抽一条，找同维度的「学界通说」条目配对；
- 出一对互斥选项：**「从其通说，录为可考」** / **「存其异说，两下并记」**；
- 选哪条记进 `S.stances`，考据判读计分，卷末回响口径随立场改变（「把异说一并存下」或「按通说落笔」）；
- 收卷报告列「考据取舍 · N 处」。

**边界写死在卡上**：
> 两条都是对史料的取舍态度，不是判定史实；争议与传说层仍按原标注，不被玩家选择改写。

也就是说，玩家选「从其通说」**不会**把那条传说变成史实。这跟「狂想档」里外星人／史前超文明的红色警示是同一条纪律。

## 五、D 跨维组合技

组合技共 **14 个**（从 5 个 → 11 个 → 14 个；后 3 个为深度补齐新增）。判定不是「凑齐指定维度」——
79 维之后那几乎不可能（实测 140 笔只见 67 条、覆盖 40 维、组合技出现 0 次），
而是「**已见 ≥3 维 + 命中该组合相关维度 ≥2 门 + 同一笔最多放 2 个**」，
卡上如实写「广博见闻 · 已见 N 维，命中相关 K/M 门（不要求凑齐全部）」。实测 140 笔出现 19 次。

| 组合 | 相关维度 | 出场 |

| 组合 | 需要维度 | 出场 |
| --- | --- | --- |
| 刊刻试本 | 工艺 + 文化 + 教育 | 刊一册试本，先在校舍传抄 |
| 授时劝农 | 水利 + 农业 + 计时 + 历法 | 按节令分水、定期课农 |
| 立坊外销 | 纺织 + 商业 + 市契 + 外交 | 设坊专织外销之货 |
| 设坊施药 | 医学 + 公共卫生 + 本草 + 法律 | 设病坊，分居给药 |
| 盟书通路 | 条约 + 礼制 + 驿传 + 移民 | 以盟书换通路并安置落户 |

后 6 个为知识补齐后新增：官定课本（BK+ST+Y+ED）、编审图籍（MP+RG+AR+ST）、备荒底册（EL+AR+SO+DI）、通关文牒（TR+RG+IS+DP）、刊布立权（PR+MR+IP+ED）、校雠立目（BK+MU+RH+AR）。每条都附一句边界：
> 组合技只表示本局已见过这些知识，不宣称历史上确曾同时施行；不作具体工坊、商路、条约的史实断言。

这把「收集册」变成了「凑齐条件才能打出的牌」，但不伪造技术传承链。

## 六、E 未走之路

每笔把没选的 2—5 条存进 `S.roads`（留最近 60 条），带年份、卷号、当时的收益预估、依据条目、失手概率。

- 卷末汇流卡新增「这一卷没走的路」，按「有依据／工程／组合技／分歧」优先挑 3 条；
- 收卷报告列「未走之路 · 近 10 条」；
- 固定写明：**「以下为当时其余选项的收益预估，仅供回看；不重放史实，也不改变已发生的编年。」**

这是「无限分支」第一次有了回头看的能力——不是真重放，也不改史实，只是让你看见自己没走的那条岔路当时长什么样。

## 七、编年时间轴

卷轴页顶部新增一条横向轴：

- 左端＝本局起点，右端＝当前年份，按年份线性排布；
- 竖线＝卷界，绿点＝亲历史事／更迭／阶段，橙点＝家族迁徙，紫点＝工程与研习节点，金色竖线＝当前；
- 点位取 `S.log` + `S.mil`，最多标 46 个；
- 写明「远古一笔跨百年，点位疏密不表示事件频率」「轴只按本局已发生的编年绘制，不补写未至之世」。

跟原有的「平行时间轴 · 政权条带」是两回事：那条横看**同年并立政权**，这条纵看**本局走过的路**。

## 八、史实与趣味的边界（继续不松）

- 工程进度、职业加成、立场、未走之路、组合技**全为游戏推演**，卡上或说明里逐条标注；
- 组合技不宣称历史因果链，分歧取舍不改写条目可信度标注；
- 史实条目仍只作「依据」，年代窗口重叠不表示人物隶属；
- 传说层、野史小说、未证实假说不进依据池；气候只作环境压力；
- 账本有上限、选项原型有衰减、同时在办工程限 2 个，避免长局滚雪球。

## 十、还能往哪走（更新版）

上一版列的五条已全部落地；知识补齐扩 6 个、深度补齐再扩 3 个组合技。剩下按价值排序：

1. **同种子对照局并排显示「未走之路」**：现在只能回看当时的预估，可以做成真·双卷并排（不改史实，只比八维与旧例）。
2. **工程失败链**：失手不只是一次数值惩罚，可以引出「抢修 / 废弃 / 换法」三笔支线。
3. **立场影响后续条目池**：这一族一贯「存异说」，后面争议类条目出现权重上调，「从通说」则通说条目更常登场。
4. **跨卷工程**：允许 3 笔以上的大工程跨卷，卷末汇流时报告「未完之工」。
5. **收卷长图**把时间轴与未走之路一并画进去，导出就能分享。
6. **补非华夏锚点**：新增 144 条里 maya 0、indus 2、nile 3、steppe 1，而 huaxia 61；这是来源限制，下轮优先补。
