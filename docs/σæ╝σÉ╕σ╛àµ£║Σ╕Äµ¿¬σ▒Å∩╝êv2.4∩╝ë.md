## 一、呼吸为什么一直没动

不是没写，是被压死了：

```css
/* 前半段 */
.stage-char{animation:breathe 4.4s ...}
@keyframes breathe{ 50%{transform:translateX(-50%) translateY(-4px) scale(1.014)} }

/* 后半段「可点可拖」 */
.stage-char{transform:translateX(-50%) translate(var(--char-dx),var(--char-dy))!important}
```

关键帧改的是 `transform`，后半段用 `!important` 把 `transform` 锁成固定值 → 动画每帧算完都被覆盖，画面纹丝不动。

改法是把呼吸换成**独立 `translate` / `scale` 属性**（CSS 渲染顺序：translate → rotate → scale → transform，互不覆盖），拖动位移继续走 `transform` 的变量。实测 1.2 秒内 `translate` 从 `-0.84px` 走到 `-3.78px`、`scale` 从 `1.003` 到 `1.013`，静止时确实在起伏。全屏预览里的立绘也一起呼吸。

## 二、待机不只是呼吸

四种轻动作按种子与笔数**固定散列**调度，约 5–9 秒一次：轻晃、轻跳、呼吸加深、摆尾式倾斜。全部只用独立属性，不碰拖动位移、不调用主随机数，同种子节奏一致。说话表演、点击、拖动、"减少动效"开启时自动让位。实测 9 秒内触发 1–2 次。

## 三、横屏：三层问题一起修

| 层 | 问题 | 修法 |
| --- | --- | --- |
| 找不着 | 三颗视图键全在 `.viewtools` 里，默认 `display:none`，只剩齿轮 | 横屏键单独露在工具条上；齿轮里保留全屏与看全部选项 |
| 点了像没变 | 窄屏下 `42vw` 舞台在 390px 手机上只有约 148px | 改成舞台铺满上半屏（40dvh）、内容在下、选项两列；实测 `stageW=390=vpW` |
| 真横不过来 | `orientation.lock` 在 `file://` 且非全屏时基本必失败 | 在用户手势内先 `requestFullscreen` 再尝试锁定；失败不假装成功 |

**必须如实说的硬限制**：网页改不了手机系统的旋转锁定。提示条写明「关闭系统竖屏锁定后把手机横过来，画面会自动铺满」，并监听 `matchMedia('(orientation: landscape)')` 自动适配；用户手动关掉的布局不会被自动覆盖。

修的过程中又抓到三个新引入的坑，一并处理：提示条把横屏按钮自己盖住（下移 + 整条 `pointer-events:none` + 工具条提层）、「知道了」被事件委托的 `if(!b)return` 提前拦掉、`applyLandscape` 误用了 `onViewClick` 内部的局部 `say()` 导致脚本报错。现在点一次切横向、点「知道了」关提示、再点一次回竖向，三步都通。
