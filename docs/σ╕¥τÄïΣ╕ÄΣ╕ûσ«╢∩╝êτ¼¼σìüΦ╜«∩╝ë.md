# 帝王与世家（第十轮）

> 用户要求「加入帝王，世家」。这一轮把两者从「人物册里零星出现过」扩成
> 两册独立数据 + 一条可代入的世家浮沉线，并接进同期卡、选项、判读题、收卷。

## 一、帝王全册：397 位 / 44 组

**不是一张「皇帝名单」，是一张分层的君主纪年锚点表。**

| 层 | 数量 | 处理 |
| --- | --- | --- |
| 可考锚点 | 387 | 按政权分组，带称谓、在位区间、继立方式、一句辨析 |
| 存疑层 | 4 | 夏代诸王，标「断代有争议」 |
| 传说层 | 6 | 三皇五帝等，**默认不进同期依据池** |

覆盖：传说与夏商、西周东周、秦汉新、三国两晋南北朝、十六国、隋唐五代十国、
宋辽西夏金元明清；域外含两河波斯、尼罗、希腊罗马拜占庭、南亚、伊斯兰世界、
草原、中美洲与安第斯、日本、欧洲中世纪近代。

**几个刻意做的分层**

- **帝号 ≠ 庙号 ≠ 谥号 ≠ 年号**：「唐太宗」是庙号、「炀帝」是谥号、「贞观／康熙／崇祯」是年号。全册以庙号／通行称法为主，年号另注。
- **「皇帝」不是通称**：法老、王、可汗、单于、大汗、哈里发、苏丹、沙阿、埃米尔、奥古斯都、巴西琉斯、天皇、将军、关白、萨帕·印卡各有制度含义，8 条「称谓与制度读法」逐条说明。
- **称制／摄政／听政单列**：吕后、王莽（摄皇帝）、武则天（临朝）、慈禧、萧太后、高太后、多尔衮——有实权而无帝号，不写成「女皇帝即位」。武则天 690—705 的武周另立一条正式称帝。
- **子婴称王不称帝**、**共和行政无单一君主**、**同一人两段在位不算两位帝王**（明英宗、唐中宗、唐睿宗、元文宗）。
- **追尊与生号分开**：努尔哈赤生前是后金汗，「清太祖」是追尊；成吉思汗生前是大汗，「元太祖」是追尊，不并入元帝系。
- **并立不排单线**：三国、十六国、南北朝、五代十国、辽宋夏金、东西罗马共治、玛雅城邦，都按政权分组，不串成一条「帝王世系」。

8 条边界读法把上面这些写死，避免玩家或后续扩展把传说层、摄政、年号混进史实。

## 二、世家全册：97 家 / 20 个类目

从先秦世卿（鲁三桓、晋六卿、齐田氏、郑七穆、楚屈昭景）、两汉外戚与弘农杨氏／汝南袁氏，
到魏晋门阀（琅琊王、陈郡谢、颍川庾、谯国桓）、五姓七望、江东士族、关陇八柱国，
再到宋士大夫（眉山苏、临川王、庐陵欧阳、吴郡范）、明清士绅（桐城张姚、海宁查陈、苏州潘、徽州汪鲍）、
晋商票号、广州十三行；域外含罗马 gens、卡佩／金雀花／哈布斯堡／美第奇／富格尔、
日本藤原氏与源平北条足利德川、古莱什与阿拔斯、孔雀笈多莫卧儿、孛儿只斤与阿史那、
拜占庭诸朝、托勒密、玛雅城邦王族与印加 panaca。

每条含：地望／别称、类目、兴起—鼎盛—散脉三段年代与文案、势力中心、
相关人物、一句**具体辨析**、域名级出处。

**八条边界读法**（也是判读题的误读项来源）：

1. 郡望／地望不等于血统凭证——「琅琊王氏」「清河崔氏」是身份标签，同称一望者未必同支。
2. 谱牒与《氏族志》不是一回事——后者是朝廷门第排序，不是谱牒真伪鉴定。
3. 「四世三公」「一门三阁老」是仕宦统计，不是世家定义。
4. 「衰落／散脉」多半是制度环境变化（科举、战乱、盐法、票号、行商制度），**不是家族人口消失**。
5. 并立与分支不作单线相续。
6. 氏族、王朝、部族、商帮、文学流派是不同层——「桐城派」「晋商」「关陇集团」不是血缘家族。
7. 联姻与收养改写的是法理所属，不是生物学世系。
8. 本局推演族人不与真实世家攀附谱牒。

## 三、可代入世家：20 家，复用六阶段年表

开局新增第四个入口「代入世家浮沉」。挑 20 家有相对清楚浮沉框架的
（琅琊王、陈郡谢、清河崔、范阳卢、弘农杨、汝南袁、兰陵萧、关陇集团、曲阜孔、
眉山苏、山西票号、美第奇、哈布斯堡、藤原北家、德川、富格尔、古莱什·阿拔斯、
莫卧儿、巴列奥略、帕伦克王族）。

阶段名改成世家语境：**兴起 → 扩张 → 鼎盛 → 转折 → 衰落 → 散脉**。
「散脉」不是「终结」：巴列奥略的「鼎盛」段甚至直接写明「本朝长期收缩，无公认极盛期，
此段只作纪年锚点」，不强行套兴衰模板。

**实现上没动原有 12 王朝**：新建 `house_entities.json`，`real.entityById` 合并查两册。
所以「12 个真实实体六阶段」「朝代长河 6 朝」等既有统计与测试口径全部不变。

## 四、怎么进玩法

| 位置 | 内容 |
| --- | --- |
| 结果卡 | 每笔按年代窗口与文明圈匹配**首次遇见**的同期在位君主 + 同期名族，各一行；明确「仅记同期，不表示受其统治」 |
| 更迭卡 | 朝代长河卷末加「本朝纪年锚点」：首尾可考在位者，注明非完整帝表 |
| 文明册 | 「帝王全册」按 44 政权折叠、「世家全册」按类折叠，已见标金 ✓；称谓读法、边界读法各自成组；并入姓氏检索框 |
| 族谱页 | 新增「名族对照」分栏，与推演族人分栏，列出兴起／鼎盛／散脉与辨析 |
| 开局 | 20 家可代入，注明「门第政治位置的浮沉，不是家族人口兴灭」 |
| 收卷报告 | 世家六阶段卡改用「散脉」措辞；加「同期在位 X / 397」「同期名族 X / 97」两格 |
| 选项 | 3 条新联动：同期在位回书、地望立册、谱牒与读法对勘（联动 14 → 17） |
| 判读题 | 24 道帝王／世家题（题库 264 → 288），误读项全部取自两册明列的边界读法 |

**同期卡不刷屏**：一位帝王在位常跨多笔、一家名族活跃常跨数百年。
第一版每笔输出 3 位君主 + 3 家名族共 6 行，实测会把编年刷满、结果卡塞爆。
改成**只输出「首次遇见」、每笔至多 1 位 + 1 家**，已见者仍算同期但不再重复落笔。
60 笔样本：帝王 53 位、世家 32 家，每笔同期卡 ≤ 2 张。

## 五、真实性边界

- 两册都是**通识级框架锚点**：年代一律区间／约略，商周、埃及王表、迦腻色伽、
  玛雅长纪历换算等标「断代有争议」；出处只给域名级检索入口、`quote` 留空、
  不伪造引文、写明**不用于学术引用**。
- 传说层不进同期依据池；考据档（strict）进一步只接纳「学界通说」条目。
- 帝王只作「某政权某时段在位」的同期锚点，**不与本局推演族人攀附血缘、
  不写成他们受某帝统治**；世家同理，地望不作血统凭证。
- 2199 条文明条目、647 位人物、1295 条姓氏、174 条地方史、75 类称谓、
  264→288 之外原有题目、难度／真实性档位／玩法／史料密度／舆图／存档全部回归通过。
- 同种子 + 同选择序列，帝王与世家记录逐笔一致，对照局仍可复盘。
