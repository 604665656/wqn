# 《上下五千年·无尽编年》文明内容考据数据报告

## 摘要

本表共 128 条，人物、工艺技术、文化、商业四维度各 32 条；华夏·黄河 32、两河·新月沃地 22、尼罗·埃及 18、爱琴—地中海/罗马 23、印度河—南亚 11、中美洲 10、欧亚草原 12，合计已覆盖七文明圈且不含政治史条目。可考年代优先用具体年份或世纪；约略年代标为 `approximate`，黄帝、尧、舜、荷马史诗传统等无法按现代历史标准确认的传主或作品归入 `legendary`。蔡伦条按“永元年间监造并推广良纸”录入，不写“发明纸”；毕昇条保留沈括《梦溪笔谈》成书于沈括在世期间（约 1086—1095 年）所记庆历年间活字法，不据此断言古腾堡系统受其直接影响；火药条区分含硝硫炭配方、唐末至五代“飞火”记录、1023 年火药作、1044 年《武经总要》军用配方四层。条目不替代游戏数值、不预设游戏效果。

## 数据规则与解析约定

1. 表头顺序固定为 `id | 年代窗口 | precision | category | title | summary | status | sources`，七列间只能有一个 `|`，摘要内不得再出现未转义的 `|`。
2. `precision` 取 `exact`、`range`、`approximate`、`legendary`；`status` 取 `学界通说`、`断代有争议`、`属传说或后世追述`。
3. `年代窗口`：单点可写 `前551年`；区间写 `前500—前300年`；约略以「约」起首；世纪写 `前5世纪`。同一条可含多地域时，窗口可并列，但主窗口置于前。
4. `category` 为维度内细分，如人物下的“思想家”“医学家”“航海家”，技术下的“冶铸”“印刷”“历法”，文化下的“文字”“宗教传播”“图书馆”，商业下的“纸币”“行会”“关税”。
5. `summary` 为可机器读取的事实句，不写“世界第一”；确有多地并行发明或存在争议时直接写明“不能据此判定最早”。
6. `sources` 引用文末编号；同一编号只能对应一个稳定 URL。本文候选来源 67 条，为避免重复编号，正文引用编号为 1—67；原检索文档 1—68 中的编号仅作检索批次记录，不进入本表。

## 条目间的承继关系与常见误说

人物条目不是帝王表，技术、医学、农业、航海与商人应占适当比例。但早期史料对个人记录本就稀疏，P014、P015、P020、P031、P033 等只能落到可确认的传统或群体，不能补足名字与生平。T006 与 C009 都写蔡伦，却分别对应“永元十七年以多源纤维进献/监造良纸”与“造纸术此前已有西汉麻纸”的边界；C011 与 C038 分别处理毕昇活字和毕昇—古腾堡关系；T002、T003、T010、T011、T016、T024、T029、T035 等均明确技术成熟是长期过程。

文化条目刻意区分三层时间。C007 的《史记》写作、传补与今本形成并非同一年；C010 的 868 年是现存最早有确切刊记的印本，不是印刷术诞生年；C037 的古腾堡《圣经》与 C038 的毕昇条目之间不存在能证明直接传播的证据。C048 与 C046 分别处理玛雅抄本制作与殖民时期转写；C043 与 C042 分别处理那烂陀寺院学习和口传经典的文本化；C021 把希伯来经典编修与作者传统并列。

商业条目不以“市场出现”替代制度。B014 是行政记录，B017 是神庙—王宫—市场混合经济，B026 是古罗马金融职能，B030 是 14 世纪实务而帕乔利 1494 年才成书，B033 的英、荷东印度公司必须分列，B048 的铁路和电报则必须分阶段。B008 把市舶设为宋初设官、元丰法后更成熟；B010 写坊市制松弛而非完全消失；B007 写汇兑凭证而非现代银行券；B046 写纸钞流通、强制兑现与贬值风险，不写成“草原统一货币”。
