## 二、抠图：0 残留是硬指标

复检查出旧 `despill` 只修实心内部，半透绒毛边还留着 292–438 个品红像素，叠到暖米纸上就是一圈玫红毛边。三步修干净：

1. `alpha=0` 区域先统一刷成中性暖米色 → LANCZOS 缩放时不再把品红混进半透边
2. 内部 + 半透边一起去溢，缩后再按 `alpha>0` 复检
3. 新八层改**无损 WebP**，杜绝有损压缩把色度重新串回来

最终八层：`holes = 0`、`alpha>0 内品红残留 = 0`。代价是这八层约 1.09 MB（其余 83 层仍 q74），单文件略胖，仍离线。

## 三、横屏：重排成真全屏 AVG

你截图里那版的问题是选项被 `grid 1fr 1fr` 挤成 99px 竖条、背景只占上半屏、提示条压住半屏。这轮全部推翻：

- 背景板 `100vw × 100dvh` 铺满整屏，立绘完整靠右、不裁切
- 左侧面板宽 47vw，选项改回**整宽竖列**（`flex-direction: column`），文字水平可读，实测卡片宽 183px
- 卷条、八维、档位等收进已有详情弹窗，不再堆在屏上
- 工具条移右上、进度 chip 放右侧、气泡放左上，三者错开
- 提示条缩成小 chip，6 秒自动收起

**仍要如实说**：网页改不了手机系统的旋转锁定。关掉系统竖屏锁定后把手机横过来，`matchMedia` 会自动适配横向布局；手动关掉的布局不会被自动覆盖。

**顺手修了个真 bug**：横屏 CSS 用 `#app > *:not(.panel)` 隐藏杂项时，把 `.stage` 也一起隐藏了，实测背景与立绘 rect 全是 0；已把舞台、进度 chip、美术条排除。

另外把 35% 半透下的白色文字光晕从 `0 0 3px` 收紧到 `0 0 2px`，并给标题／正文／选项主文字补了极细同色描边。实机截图里之前发虚的正文现在笔画立得住，透明度档位没动，仍默认 35%。
