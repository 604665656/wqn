# 亲子链修复：二代没结婚，三代怎么来的（第九轮）

> 缘起：用户发来关系图截图——4 个点，1 代「姚简／子叔」是夫妇（蓝线），
> 2 代「妫元」点开写「父·姚简 母·子叔」，可 3 代「风成公」也连在
> 1 代两人身上，而 2 代没有任何配偶线。问：**二代没结婚，三代怎么来的？**

---

## 一、截图里其实是三个叠在一起的真 bug

| # | 病根 | 表现 |
| --- | --- | --- |
| 1 | **单亲出生** | 旧版 `attachBirth(S,babe,head,null,rnd)` 只传一个家长，`parent2` 取 `head.spouse`（族长一更替常为空）。于是大量孩子只有一个父／母，界面上看起来就是「没结婚却有了下一代」。 |
| 2 | **世代乱标** | 新生儿 `gen = S.gen + 1`，而 `S.gen` 是个会随继立虚跳的计数器，**不是亲子链**。同一对夫妇的两个孩子能被标成 2 代和 3 代；绝嗣立新还会一次跳 2 代。 |
| 3 | **裁剪把父辈删了** | 长局裁剪只保留「在籍者 + 最近两位故去族长 + 两层父辈」，故去者的双亲常被清掉，关系图上就少掉一边的连线，看起来更像单亲。 |

量化复现（旧版，40 笔）：8 个有双亲记录的人里 **8 个单亲、8 处世代错位**，
7 个「父辈未婚」。截图正是这个状态。

---

## 二、这轮怎么改的

**1. 先成家，后添丁**
`engine.step` 把 `matchUnmarried` 挪到 `advanceFamily` 之前。
新增 `birthCouple(S,rnd)`：只从**一对互为配偶、且都在册在籍**的成年人里挑，
优先最高世代的一对；没有现成夫妇就现场配一对，配成就生，配不成就**不生**。
`attachBirth` 现在强制接收 `a,b` 两人，双方不是配偶就补配，补不成直接返回 `null`。

**2. 世代只由双亲决定**
```
babe.gen = max(a.gen, b.gen) + 1
babe.birthPair = [a.id, b.id]      // 出生时的夫妇快照
babe.birthSpouseOK = true
```
父母日后丧偶再配、或一方离册，**都不改写这条出生记录**；
`S.gen` 改为每笔末跟随在籍族人的实际最大世代，不再自己虚跳；
绝嗣立新＝旁支过继／重新立户，接续当前世代而不是凭空加一代。

**3. 裁剪改成一次性 BFS 闭包**
每笔末（而非每个 25 年小段）跑一次：在籍者 + 最近两位故去族长 +
「被在册者引用为双亲／配偶」的传递闭包，上溯限 3 代、故去者封顶 40 位。
这样既不丢父母，也不让 `S.fam` 无限膨胀。修正前 200 笔会堆到 224 人，
修正后 31 人，200 笔 1.4 秒。

**4. 旧档自动校正**
`normalize(S)` 在载入时：给单亲孩子补 `parent2`（优先在册配偶，否则同代补配）、
按 `max(双亲.gen)+1` 重算世代。刷新就修好，**不用清档重开**。

**5. 界面自洽**
- 关系图自环（「庶支／旁支 · 自己」）不再画成一条边，点选面板也过滤自指
- 顶栏「第 X 代」改读当家本人的 `gen`
- 关系图说明补一句「孩子只从已配对的夫妇出生，世代按双亲 +1 计算」
- `people.summary` 的世代统计不再掺 `S.gen`

## 三、修完之后

- 5 个文明圈 × 40 笔：**单亲 0、出生对不符 0、无夫妇快照 0、世代错位 0**
- 5 圈 × 60 笔累计违例全 0（huaxia / nile / indus / maya / aegean）
- 开局三人：1 代夫妇 + 他们的 2 代孩子；要出现 3 代，必须先有 2 代夫妇
- 旧档坏数据（单亲 + gen=9）经 `normalize` 后双亲补齐、世代重算为 2
- 200 笔长局 `S.fam` 最大 31 人，逻辑测试全绿、浏览器零报错、档位专项全绿

## 四、边界没松

- 这些都是**本局推演生成的人物与关系**，不是任何真实家族的世系；
  继嗣制仍是「按文明圈抽签的玩法近似」，不是该文明全域断言。
- 再配、从妻居、入赘、母系承祧都照旧保留；出生快照只记「这一对夫妇生了这孩子」，
  不推断生物学亲子、不写血缘纯度。
- 史实条目、2199 条文明内容、647 位人物、75 类称谓逐字未改；
  难度／真实性档位／玩法／史料密度／舆图／存档／同种子复盘全部回归通过。

## 五、还能往哪走

1. 关系图可加「按类别筛选边」与拖动布局，边多时更易读。
2. 出生快照可扩展为完整的「出生事件」编年条目（含年份、居制、族册归属）。
3. 绝嗣补员目前是同代成年人入册、无双亲记载，可改成「旁支过继」并记一条过继关系。
4. 长局逻辑测试因 21×800 笔 + 全部断言约 4—5 分钟，可拆成分组并行。
