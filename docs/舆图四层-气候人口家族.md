## 一、这一轮加了什么

| 图层 | 画的是什么 | 数据从哪来 |
| --- | --- | --- |
| **政权**（原有） | 29 个政权核心区虚线示意，不是国界 | `data/atlas.json` + `entities.json` |

## 二、气候图怎么来的，为什么不是「气候地图」

`geoclimate.json` 的 32 条事件只标了 `regions`（文明圈或 `*`），**没有经纬度范围**。所以脚本 `tools/build_layers.js` 这样处理：

- 区域性事件 → 取该圈**已考据地理单元**的近似中心点，求包围盒，外扩一点画示意椭圆；
- 全球性事件（9 条，如全新世大暖期、海平面上升）→ **不画任何边界**，只在图顶加一条淡蓝色提示条，图例写「全球性气候现象 N 条（不画边界）」。

配色按类别：暖湿／暖期偏橙黄，冷干／冷期偏蓝，干旱偏赭，水文／海平面偏青，火山偏紫。同期事件按年份窗口筛选，最多画 8 个椭圆，避免糊成一片。

**硬边界**（界面顶部与每条事件都写）：
> 气候影响区是示意椭圆，不是实测范围；气候只作环境压力，**与社会兴衰的时间重合不等于已证因果**。

## 三、人口热力：最需要说清楚的一层

历史没有逐朝人口栅格数据，所以这层**不是人口统计**，也没有任何人口数字。

做法：
- 29 个核坐标**全部复用** `geoclimate.json` 里已考据的地理单元，不新增一个未经考据的地点；
- 9 个时代各给 7 个文明圈一个**通识级相对权重**（农业起源多中心 → 古典帝国核心区 → 中古欧亚城市带 → 大航海后大西洋沿岸 → 工业与当代城市化），年份之间线性插值，拖滑杆不会跳变；
- 单元类型微调：冲积平原／河谷 ×1.18，沙漠／高原 ×0.72，海岸 ×1.06；
- **按圈聚合再画渐变**：否则单元多的圈（华夏 6 个、爱琴 5 个）会因光斑叠加显得「人口更多」，那是单元数量的假象，不是权重。单元级只留一层固定低亮细节。

界面写死一句：
> 人口热力不是历史人口统计，没有逐朝人口数字；只表达「相对聚集重心往哪偏」，**不能读成人口数量、密度值或跨文明人口比较**。

列表里的百分比也只是示意权重，不是人口占比。

## 四、家族分布图：唯一会「动」的一层

这层是玩家本局的数据，和史实人口无关：

- 开局一支人聚在相邻两三处地理单元（不是一上来散居全球）；
- 新生儿继承当家落脚点，登记进 `S.famPlaces`；
- **点「迁徙」类选项会真的搬人**：约半数在籍族人（当家随行）迁到新单元，写 `S.migrations`，进里程碑与编年；地图上出现虚线迁徙连线；
- 特殊选项「据舆地〈某地理单元〉之势」会把该单元指定为目的地；
- 朝代长河的跨朝记录现在附上「散居 X 地几人」；
- 族谱页新增「落脚地 / 迁徙足迹」，舆地页的家族列表与之对应；
- 旧存档刷新时自动按本圈地理单元补齐落脚点，不用清档。

金圈大小按人数，当家所在加粗外环并标名。点选金圈会写「本局家族据点 · 推演数据，不是史实人口」。

## 五、玩法上的联动

这一轮不只是多画三张图，而是让图参与抉择：

1. **气候进选项**：上一轮的 `SP_CLIM` 原型已经能生成「遇〈全新世大暖期〉之变，开仓平粜、改种耐旱之作物」；现在舆地页能直接看到同期哪几条气候事件在生效，点椭圆可读证据与免责。
2. **地理进选项**：`SP_GEO` 原型指定落脚单元，选中后家族分布图上的金圈真的移动。
3. **人口重心随年份变**：拖滑杆能看到重心从多中心农业起源，慢慢偏向古典帝国核心区、再偏向近代大西洋沿岸；这是「看历史」而不是「改历史」。
4. **家族跨越改朝**：长河模式里同一支人的落脚点会随迁徙累积，收卷时能看到一支人走过哪些地理单元。

## 六、界面与交互

- 图层按钮 `✓ 政权 / ✓ 气候 / ✓ 人口热力 / ✓ 家族`，默认四层全开，点一下即关；关掉气候后画布像素确实变化（专项测试用 `toDataURL` 前后比对）。
- 图例随图层开关实时变化，列出「并立政权 N 个 / 气候影响区 N 条 / 人口重心 / 本局家族 N 人」。
- 列表四块：政权（起讫与说明）、气候（同期事件、年代、类别、因果免责）、人口重心（时代与前五单元）、家族分布（各据点人数、当家、迁徙足迹）。
- 缩放后文字分层出现：默认只留家族当家标签；放大到 2.6 倍才铺开政权名，3.6 倍才标气候事件名，避免东亚一带叠成一团。

## 八、如实没做的

- **没有精确历史国界**：多数时段本就不可考，虚线只是政权核心区示意。
- **没有真实人口数字 / 栅格**：热力是相对重心示意，不作数量断言。
- **气候影响区不是实测边界**：由已考据地理单元近似勾画，全球性事件不画边界。
- **家族分布是推演**：不是史实人口，也不是史实人物履历。
- 清／民国／当代仍无编造的六阶段年表；2026 年后不外推。
