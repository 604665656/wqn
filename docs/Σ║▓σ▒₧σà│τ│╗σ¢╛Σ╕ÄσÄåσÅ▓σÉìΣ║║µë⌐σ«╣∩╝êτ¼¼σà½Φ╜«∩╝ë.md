## 二、亲属关系：开局不一定父系

**四种继嗣制**按文明圈的史料可见做法抽签（权重是玩法近似，不是全域断言）：

| 制度 | 本局效果 |
| --- | --- |
| 父系继嗣 | 父方计世系、承祧与家产 |
| 母系继嗣 | 母方计世系，舅父常居监护之位 |
| 双系并计 | 父方母方两系同时入册 |
| 从妻居 / 入赘 | 夫就妻家，子女归妻方族册，夫标「赘婿」 |

实测 168 局分布：父系 87 / 双系 44 / 入赘 19 / 母系 18 —— **开局确实不总是父系**。
母系或从妻居时，开局承祧方设为女性；父系为男性；双系两者皆可。
界面写明「同一文明在不同时期、地域、阶层做法差别很大，父系、母系、双系、
从妻居往往并存」，并给每个文明圈单独一句史料限制说明：
**印度河文字未破译，继嗣无直接材料，此处只作玩法近似**；草原与中美洲城邦差异大，
不排他；埃及王室近亲婚不与平民同俗；两河女性财产权另有条文，不简化。

**婚姻写回**：每笔给未婚在籍成年人连夫妇关系，登记 `spouse` 双向、居制
（从夫居／从妻居／另立新居／两可居）、赘婿与户主标记。裁剪在册故去者时
保留双亲链两层 + 配偶 + 配偶双亲，保证姻亲称谓推得出来。

## 三、称谓穷举：75 类，全部由关系链推出

不是写死名单，而是 `kinship.js` 从实际的 parent / parent2 / spouse / children /
siblings 链逐层推导。包含你点名的：

> 夫、妻、配偶、**赘婿**、继室、继父继母、养父母、嫡长承祧子、
> **姑父**（父之姊妹之夫）、姑母、伯父叔父、伯母／叔母（婶）、
> 舅父、**舅母（舅妈）**、姨母、**姨父**、
> 堂兄弟姊妹、姑表／舅表／姨表、侄侄女、甥甥女、
> 岳父岳母、翁（公公）姑（婆婆）、内兄内弟、大姨子小姨子、
> 大伯子小叔子、大姑子小姑子、嫂、弟媳、姊夫妹夫、
> **连襟**（姊妹之夫互称）、**妯娌**（兄弟之妻互称）、亲家、
> 外祖父母、外孙外孙女、宗子嫡长、庶支旁支、过继立嗣、绝嗣，
> 以及从夫居／从妻居／另立新居／两可居／收继婚等制度性称谓。

族谱页有「亲属称谓穷举」折叠册（75 类，标「✓ 本局已见」），
每位族人卡里列出本人实际推出的称谓（含对象姓名与类别），最多 18 条。

**边界**：称谓以汉语亲属系统为主，用于本局读法；其他文明的本土称法
不逐一对译，避免把汉语称谓当作当地制度的事实。妾、收继、王室近亲婚等
按历史制度性称谓记录，不作现代价值判断，也不倒灌进当代伦理。

## 六、还能往哪走

1. **逐位升级出处**（仍是第一优先的内容债）：610 位新增人物、
   1174 条姓氏、283 条术语锚点仍为域名级入口 + 引文留空。
2. **人物生平扩到全册**：76 份四段生平只覆盖最著名的一批，其余 570 位只有梗概。
3. **本土称谓对译**：目前 75 类是汉语系统，可为罗马、阿拉伯、日本、
   玛雅等各配一套本土称谓，并注明不对译。
4. **关系图布局**：现在是按代分层直线，可改力导向布局与拖动节点；
   边多时会略密，可加按类别筛选。
5. **居制影响玩法**：目前从妻居／入赘只改族册归属与称谓，可让它真改
   迁徙、家产与继承权重。
