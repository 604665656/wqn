## 一、先补缺素材（10 张做满即停）

| 类别 | 本轮新增 |
| --- | --- |
| 角色层 | 扶犁、簸扬、削简、挑灯、播鼗、结网、舆载、炊釜（75 → **83**） |

83 层 `binary_fill_holes` 全为 0，叠到任一背景板后品红残留 0 像素。8 个新层按更具体的关键词**优先于通用映射**接入选项表演：`扶犁|耦耕|深耕|犁` → 扶犁、`簸扬|扬糠|筛` → 簸扬、`削简|书契|刀笔` → 削简、`挑灯|夜分|守读` → 挑灯、`播鼗|摇鼓` → 播鼗、`结网|罟|罾` → 结网、`舆载|辇|任重` → 舆载、`炊釜|灶|粒食` → 炊釜。下一批 8 层只登记不占位。

## 二、把 v2.2 的人声表演钉进浏览器回归

v2.2 加了四档声线、六种语气音、说话表演，但只做了逻辑层断言。本轮在浏览器全流程里补了六项实机检查：设置页「向 导 人 声」卡存在、四档声线按钮、六种语气试听、表演开关两态、语气音开关两态、`a11y.setVoicePack` 接口可用。专项再加 4 组断言（新层命中、场景解锁、关卡名无占位、声线接口）。

**顺手修一个计数污染**：声线档按钮原先复用了环境音卡的 `.wxpick` 类，导致「可选环境音 12 项」的统计里多出 4 个按钮。拆成独立 `.vppick`（样式共用、计数独立），环境音计数恢复 12。

## 三、核对一条旧需求

「预览图点击全屏的时候对应选中的场景也要全屏」——查过 `openPreview`：点缩略图时会 `set('backdrop', key)` 并重取 `bgURL()`，预览浮层里点场景名也会整屏换板、标题同步更新。这条已成立，不用另改。

## 四、边界与验证

- 史实、2199 条考据条目、帝王世家、存档与分享串一字未改；本轮全是美术、本机显示与测试。
- 所有互动不调用主随机数，同种子仍逐笔可复盘；场景只是美术底色，不表示所在地。
- 声线仍是浏览器系统语音的音高／语速组合，语气音是合成短音，**不是配音包、不联网加载音频**。
- 送审版同步带全部新功能，`audit_copy --strict` 六类敏感措辞 **0 命中**。
- 八套回归全绿、浏览器零报错。
