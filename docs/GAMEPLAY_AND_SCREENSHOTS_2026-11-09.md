## 1. 哈士喵的测试屋（新上架）

**在线玩**：https://www.bilibili.com/toy/hashimiao-quiz-avg/index.html
**完整工程**：https://github.com/604665656/hashimiao-quiz-avg

### 玩法是什么

一间会念题的测试屋：由「眼镜猫」念题，你做选择，最后给一段**可以推翻的观察**。
不是标准心理测评，结果只当聊天起点。内容规模：7 条分类轴 / 48 个取值 / 7 个分区 /
18 套卷（17 套可玩 + 1 套规格说明）/ 174 道题 / 9 种卷型引擎。

### 怎么操作

1. **主页三层**：封面 → 分区书架 → 信息抽屉。点「开始 · 四象速测」走快速通道，
   点「全部测试 →」进分区书架挑卷。
2. **答题**：看事件 CG 与逐字机对白，点选项作答；可开 `AUTO` 自动推进、`SKIP` 跳过、
   `LOG` 回看记录。
3. **表演**：封面 → 章节转场 → 事件 CG 相框 → 逐字机 / 名字牌 / 立绘差分 → 结果揭晓；
   8 张表情姿态差分、10 张场景板、8 张情境 CG，带随机眨眼、说话抖动、结果聚光。
4. **互动彩蛋**：哈士喵可以点、可以拖（见「拖动中」截图）。
5. **存档**：`localStorage` 断点续玩，中途退出后封面会出现「继续上次」。音频默认全关，
   只有你点开才响。竖屏优先，也支持横屏。

> 名称说明：上架名统一为「哈士喵的测试屋」；念题角色仍叫「眼镜猫」，是角色设定，未改动。

## 2. 哈士喵勇闯魔法禁书目录 v0.81

**在线玩**：https://www.bilibili.com/toy/hsm-toaru/index.html
**完整工程**：https://github.com/604665656/hsm-toaru

### 玩法是什么

非官方同人 AVG，**33 关**。每一关固定三段式：**阅读对白 → 回答问题 → 查看解锁词条**。
答对推进剧情并解锁资料，配合关卡地图、资料库与人格测试等附属页签。

### 怎么操作

1. 首屏点「开始冒险 / 从第一关开始」，或点「关卡地图」直接选关。
2. **推进对白**：点击画面任意处，或点「下一句」。
3. **跳到选项**：点 `⏭` 直接跳到本题选项，不用逐句点完。
4. **切横屏**：点 `⛶`；另有「自动」「表情」「背景：开」等开关。
5. **氛围标签**：设置里可切换（仅文字标签，不播放音频）；全程不请求麦克风。
6. 顶部显示 `0 / 33 关卡`、`6 / 152 词条` 进度，资料库与素材展柜随时可回看。

> 已知遗留：首屏徽章显示 `VERSION v0.65`，是上游归档遗留，与本次 v0.81 交付包不一致，
> 不影响游玩；按「不改源文件」原则如实保留。

## 3. 杯雪 · 互动游戏集

**在线玩**：https://www.bilibili.com/toy/beixue/index.html
**完整工程**：https://github.com/604665656/beixue

### 玩法是什么

《杯雪》同人互动游戏：**二十四关 · 七卷 · 四模式 · 三档难度**，单文件离线可玩。
虽然名字带「游戏集」，平台侧**仍是一个单 TOY**，一个链接进去就是完整游戏。
支持手机竖屏 / 横屏 / 桌面三种尺寸。

### 怎么操作

1. 进入「杯雪 · 游戏总站」大厅，点「**继续上次 · 你是《杯雪》里的谁**」续玩，
   或点「**从头开始**」重新开局。
2. 点「**展开全部 关卡地图 · 进度 · 模式 · 难度 · 说明**」查看 24 关结构与四种模式、
   三档难度，再选场景首关进入。
3. 顶部 `横屏` 切换方向，`★072` 查看收集，`设置` 调整选项。
4. **点选项会触发表演**：换表情层 + 点头 / 摇头 + 名牌跟随说话人。

> 已知问题（上游 README 如实记录）：点击 / 拖动立绘**没有**表演（点选项才有）；
> 轻量版不可用；音频文件为 0，当前是无声版。`PROC_ART` 的 TDZ 报错已修。

## 4. 上下五千年 · 无尽编年 v4.2 · build 33

**在线玩**：https://www.bilibili.com/toy/wqn/index.html
**完整工程**：https://github.com/604665656/wqn

### 玩法是什么

一支人、一座城、某一个人，从公元前 5000 年一路点下去的**分卷编年**互动叙事。
你不是在读一段写好的历史，而是顺着每次选择往下走；**每 12 笔汇成一卷，卷卷可收**。
v4.2 规模：**240 层 · 29 场景板 · 129 关**。

### 怎么操作

1. 浏览器打开即玩，**不需要联网**；工程里 `dist/wqn.html` 是主站，

2. 首屏点「**下一句**」推进，跟着猫立绘与文案一路选择。
3. 卷轴式布局会横向展开，桌面端建议宽窗口；卷成后可回收查看。

## 5. 喵琴师 · CatKeys · 哈士喵的钢琴

**在线玩**：https://www.bilibili.com/toy/n6ivNJRNYEx64flD/index.html
**完整工程**：https://github.com/604665656/catkeys

### 玩法是什么

单文件 Web **钢琴节奏跟弹**游戏，主角是开源动效吉祥物哈士喵。
**65 首公有领域分级曲目**，Lv.1~Lv.10 + 演奏级，跟弹打分给 ★，熟练度逐级解锁。
带 10 项成就系统（初遇 / 全连 / 完美主义 / 百连 / 三星演奏家…），
以及体力系统（上限 5 点、每 60 秒回 1 点、每日 20 局）。

### 怎么操作

1. **选模式**：`自由弹` / `跟弹打分` / `🎯 演练` / `🐱 跳跃`（哈士喵死亡跑酷）。
   消耗体力的只有「跟弹打分」和「跳跃」，演练与自由弹不消耗。
2. **看键位**：自适应键位——手机 13 键、平板 25/37 键、电脑 61 键；
   可切「双手键位 / 自动分区 / 音符居中」，`📐` 锁横屏或竖屏。
3. **开练**：点曲目下拉（如 `C 大调音阶练习`），调 `速度` / `音量` / `音色`，
   点右侧「**开始练习**」；音符从上往下落到判定线时按对应琴键。
4. **看结果**：顶部 `SCORE / COMBO / ACCURACY` 与右上 `PERFECT` 实时更新。
5. 真钢采样联网懒加载（CC BY 3.0），离线时自动降级为合成双音色 + WebAudio 混响；
   6 套主题、音符彩虹模式、特效开关在「画面」里调。

## 6. 音乐节奏游戏：嘶恍而过的青葱岁月

**在线玩**：https://www.bilibili.com/toy/yyjzshegdqcsy/index.html
**完整工程**：https://github.com/604665656/qingcong-rhythm

### 玩法是什么

不依赖框架、单文件的 **4 轨下落式音游**，示例曲《嘶恍而过的青葱岁月》。
谱面由音频分析离线生成（STFT 谱通量检测音头），跟着真实音头走，不套固定 BPM 网格。
三难度、准确率评级、本机最佳分，**50 连击进 FEVER ×1.5**。

### 怎么操作

1. **键位**：`D F J K` 四轨，也支持方向键 / 触屏点按 / 手柄（A B X Y、十字键、左摇杆）。
2. **判定**：PERFECT ±85ms · GREAT ±140ms · GOOD ±200ms · MISS ±280ms；
   觉得偏手可在设置里调「判定偏移」。**跨轨宽容 100ms**：点偏一格不算空按。
3. **长按**：按住期间每 0.22s 持续得分，按满出 `HOLD` +150；中途松开只丢收尾奖励，
   不判 MISS、不断连。
4. **连线滑条**：带箭头的相邻轨音符按住横向滑过去即可（间隔 ≤0.45s、跨 1~2 格、链长 ≥3）。
5. **太鼓模式**：红 = 咚 / 蓝 = 咔，谱面由四轨谱自动派生，命中即敲合成鼓声。
   切换模式时会立刻弹出该模式玩法说明。
6. 4 套主题（青葱 / 樱粉 / 暮蓝 / 猫橙）、逐字卡拉 OK 歌词、预置短语弹幕、
   按模式分榜的排行榜、云存档、体力 / 分享得体力都在标题页与设置里。

> 提示：headless 无音频环境下会走「静音试玩」降级（节拍与判定照常），
> 因此下面首屏图用工程内 CDP 真机截图，能完整显示标题页与玩法弹层。

## 附：单 TOY 与合集

- 上面 6 个**全部是单 TOY**：一个 Toy = 一个游戏入口，各有独立链接与互动统计。
- 账号里目前**没有 `COLLECTION` 类型的合集 Toy**（0 个）。

## 附：欢迎实测、提 BUG、给建议

6 款都是打开链接就能玩，不用下载、不用装环境。最想验证：

- 能否从开头一路玩到结尾，有没有卡住 / 点不动；
- 章节转场、选项分支、结果揭晓是否连贯；
- 刷新或重开后「继续上次」还在不在；
- 立绘 / CG / 背景板有无裁切错位、白屏、加载慢；
- 手机竖屏、平板横屏、电脑浏览器下的布局。

反馈直接在这条动态 / 专栏 / 文章评论区说即可，能带上
