三、每款游戏怎么玩（补上的玩法介绍）

以下玩法说明全部来自各游戏工程自带 README 与真实浏览器画面，未作推测。

1）哈士喵的测试屋
「眼镜猫」念题，你做选择，最后给一段可以推翻的观察——不是标准心理测评，结果只当聊天起点。规模：7 条分类轴 / 48 个取值 / 7 个分区 / 18 套卷（17 可玩 + 1 规格说明）/ 174 道题 / 9 种卷型引擎。
操作：主页三层是「封面 → 分区书架 → 信息抽屉」，点「开始 · 四象速测」走快速通道，点「全部测试 →」进书架挑卷；答题看事件 CG 与逐字机对白，点选项作答，可开 AUTO 自动推进、SKIP 跳过、LOG 回看。表演链路为封面 → 章节转场 → 事件 CG 相框 → 逐字机 / 名字牌 / 立绘差分 → 结果揭晓，带随机眨眼、说话抖动、结果聚光。哈士喵可以点、可以拖；localStorage 断点续玩，退出后封面出现「继续上次」。

2）哈士喵勇闯魔法禁书目录 v0.81
非官方同人 AVG，33 关，每关固定三段式：阅读对白 → 回答问题 → 查看解锁词条。答对推进剧情并解锁资料，配关卡地图、资料库、人格测试等页签。
操作：点「开始冒险」或「关卡地图」选关；点击画面任意处或点「下一句」推进对白；点 ⏭ 直接跳到本题选项；点 ⛶ 切横屏；另有「自动」「表情」「背景：开」等开关。设置里可切换氛围标签（仅文字标签，不播放音频），全程不请求麦克风。顶部显示 0 / 33 关卡、6 / 152 词条进度。

3）杯雪 · 互动游戏集
《杯雪》同人互动游戏：二十四关 · 七卷 · 四模式 · 三档难度，单文件离线可玩，支持手机竖屏 / 横屏 / 桌面三种尺寸。虽然名字带「游戏集」，平台侧仍是一个单 TOY。
操作：进入「杯雪 · 游戏总站」大厅，点「继续上次 · 你是《杯雪》里的谁」续玩，或点「从头开始」重新开局；点「展开全部 关卡地图 · 进度 · 模式 · 难度 · 说明」查看 24 关结构再选场景首关。顶部「横屏」切换方向、★072 查看收集、设置调整选项。点选项会触发表演：换表情层 + 点头 / 摇头 + 名牌跟随说话人。

4）上下五千年 · 无尽编年 v4.2
一支人、一座城、某一个人，从公元前 5000 年一路点下去的分卷编年互动叙事。不是读一段写好的历史，而是顺着每次选择往下走；每 12 笔汇成一卷，卷卷可收。v4.2 规模：240 层 · 29 场景板 · 129 关。
操作：浏览器打开即玩，不需要联网；首屏点「下一句」推进，跟着猫立绘与文案一路选择。卷轴式布局横向展开，桌面端建议宽窗口，卷成后可回收查看。

5）喵琴师 · CatKeys · 哈士喵的钢琴
单文件 Web 钢琴节奏跟弹游戏，65 首公有领域分级曲目（Lv.1~Lv.10 + 演奏级），跟弹打分给 ★，熟练度逐级解锁；带 10 项成就系统与体力系统（上限 5 点、每 60 秒回 1 点、每日 20 局）。
操作：选「自由弹 / 跟弹打分 / 演练 / 跳跃」四种模式；自适应键位（手机 13 键、平板 25/37 键、电脑 61 键），可切「双手键位 / 自动分区 / 音符居中」；点曲目下拉（如 C 大调音阶练习），调速度 / 音量 / 音色，点「开始练习」，音符落到判定线时按对应琴键；顶部 SCORE / COMBO / ACCURACY 与右上 PERFECT 实时更新。真钢采样联网懒加载，离线自动降级合成双音色。

6）音乐节奏游戏：嘶恍而过的青葱岁月
4 轨下落式音游，谱面由音频分析离线生成（STFT 谱通量检测音头），跟着真实音头走，不套固定 BPM 网格。三难度、准确率评级、本机最佳分，50 连击进 FEVER ×1.5。
操作：D F J K 四轨，也支持方向键 / 触屏点按 / 手柄。判定窗口 PERFECT ±85ms / GREAT ±140ms / GOOD ±200ms / MISS ±280ms，可在设置调「判定偏移」；跨轨宽容 100ms，点偏一格不算空按。长按每 0.22s 持续得分，按满出 HOLD +150，中途松开只丢收尾奖励、不判 MISS、不断连；带箭头的连线滑条按住横向滑过去。切「太鼓模式」后红 = 咚 / 蓝 = 咔，谱面由四轨谱自动派生，切换模式会立刻弹出玩法说明。另有 4 套主题、逐字卡拉 OK 歌词、排行榜、云存档、体力 / 分享得体力。

五、重点是可玩性，麻烦帮我走一遍

6 款都是打开链接就能玩，不用下载、不用装环境。最想验证这几件事：

  • 能不能从开头一路玩到结尾，有没有哪关卡住、点不动；
  • 流程是否连贯，章节转场、选项分支、结果揭晓有没有跳不过去或重复出现；
  • 存档是否靠谱，刷新或关掉重开后「继续上次」还在不在；
  • 画面与性能，立绘、CG、背景板有没有裁切错位、白屏、加载特别慢；
  • 设备兼容，手机竖屏、平板横屏、电脑浏览器下布局是否正常。
