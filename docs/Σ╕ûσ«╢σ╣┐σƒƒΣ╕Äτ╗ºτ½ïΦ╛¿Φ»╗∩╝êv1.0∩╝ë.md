## 一、版本号（你上一条的要求）

不是写在回复里的一句话，是进了工程的机制，见 `docs/版本记录.md`：

- `data/version.json` 存 `version / build / date / codename / pending / changelog`
- `node build.js` 读到 `pending` 就自动 **minor +0.1**、build +1、写 changelog、清空 pending
- 同一轮反复构建**不刷号**；首轮建立基线 v1.0
- 开局页、设置页、收卷报告、`<title>`、HTML 头注释都显示版本
- 存档 `S.ver` 写入，旧档 `migrate` 自动补

**顺手修的真问题**：版本补写原本写在 `migrate` 的族谱检查之后，
字段不全的旧档会在 `if(!o.fam) return null` 处提前返回、漏掉版本字段。
已提到函数开头，并用「删掉 ver 的完整旧档」做回归断言。

## 三、可代入世家 20 → 30 家

复用六阶段年表，末阶段一律 **「散脉」**，不是「终结」：

托勒密、塞尔柱、萨法维、笈多、马拉塔联盟、金雀花、卡佩—瓦卢瓦—波旁、
留里克—罗曼诺夫、孛儿只斤与北元、阿兹特克三方联盟。

每条都在节点里写了该断的真话，例如：
- 托勒密：「法老」是埃及王号，与马其顿王族身份并存；前 30 年是并入行省，不是家族灭绝
- 塞尔柱：哈里发保留宗教名义、苏丹掌军政，两层要分开；罗姆支系另续
- 马拉塔：「帝国」实为后来形成的联盟，几家互不统属，不是一族分封
- 阿兹特克：三城并立，统治者称特拉托阿尼，「皇帝」是误写
- 孛儿只斤：1260 年后已非统一指挥，北元与「蒙古帝国」不是同一政治实体

## 四、帝王在位时间条

文明册「帝王全册」里新增一条可交互的横向时间条：

- 下拉切 **44 个政权**，默认选本圈中「非传说且条目最多」的政权（避免一开就是 6 行传说层）
- ＋／－／复位缩放，放大后横向滚动；悬停条上可看姓名、年代、继立方式与辨析
- **六类分色**：可考在位 / 旁支·推举·过继 / 摄政·共治·并立 / 废立·内禅·复辟 / 存疑层 / 传说层
- 传说与存疑用虚线；横轴只取该政权自身年份区间，刻度 5 格

边界写在图例下：条长只表示年代窗口，不表示权力强弱；共治、废立、追尊、
并立已在色别里分开，**不排成前后相续的帝系**。
